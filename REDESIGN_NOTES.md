## 🎬 Animations & Effects

### New Animations Added

1. **Crown Pulse** - Logo crown pulses continuously
   - Scale from 1 to 1.1
   - Duration: 2 seconds
   - Creates regal feeling

2. **Crown Bounce** - Hero crown animation
   - Bounces up and rotates
   - Creates dynamic hero section
   - Infinite loop with easing

3. **Gradient Shimmer** - Title gradient animation
   - Gold gradient flows across title
   - Creates premium feel
   - 3-second duration

4. **Shimmer Background** - Subtle dot pattern animation
   - Moves diagonally across hero
   - 20-second cycle
   - Very subtle, adds polish

5. **Fade In Up** - Section entrance animation
   - Elements fade in as you scroll
   - Uses Intersection Observer
   - Applied to all cards and sections

6. **Hover Effects**
   - Cards lift up on hover (translateY)
   - Color transitions smooth
   - Borders animate to gold
   - Shadows increase

7. **Parallax Scrolling** - Hero content
   - Moves slower than scroll
   - Creates depth effect
   - Fades as you scroll down

## 🎨 Color Customization

Easy to customize! Edit styles.css (lines 8-15):

```css
:root {
    --primary-color: #D4AF37;        /* Main gold */
    --secondary-color: #E5C158;      /* Light gold */
    --dark-bg: #0a0a0a;             /* Dark background */
    --dark-card: #1a1a1a;           /* Card background */
    --text-light: #e0e0e0;          /* Light text */
    --accent: #FFD700;              /* Bright gold */
}
```
